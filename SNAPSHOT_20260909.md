# Before map-aware 100 km/h experiment

This commit preserves the current ROS1 workspace sources and team-demo settings
before map-aware speed changes. The controller is a locally modified Autoware AI
MPC (including ZOH steering dynamics and cost changes), not an unchanged upstream
controller. Earlier package README descriptions may predate those changes.

The team-demo reference is `run_team_demo.sh` and
`artifacts/controller_validation/2026-09-09/team_demo/` (four source/config files).
No 100 km/h simulator validation has been performed.

## Files intentionally retained only on the workstation

- `src/morai_kcity_hd_map/raw_mgeo/`, map OSM, RDDF, and preview images:
  simulator-derived data; public redistribution permission has not been verified.
- `artifacts/` raw recordings, analyses and binary snapshots (~15 GB), except the
  team-demo runner/configs above; `backups/` also remains unchanged locally.
- Generated build/devel/install trees and Python caches.

The public Git snapshot is therefore a source/configuration backup, not a complete
copy of the local data and recordings. A new checkout needs authorized map/RDDF
data and ROS dependencies before it can run the same scenario.

Local map SHA-256:
`ad496d66ab211d86373fbc8534fc10ba3ea080487fd29bed465e40c01b7911ab`.
The map has 581 ordinary lanelets at 60 km/h and 53 high-speed lanelets with the
custom competition attribute `contest_speed_limit=unlimited`.

The modified qpOASES vendor and upstream source files are tracked as regular files
(not Git links), retaining their original licenses. Their nested local Git
metadata is not uploaded.
